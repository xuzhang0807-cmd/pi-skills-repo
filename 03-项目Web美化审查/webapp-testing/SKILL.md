# 网页实际运行检查

来源与适配差异见 [ORIGIN.md](ORIGIN.md)。`scripts/smoke.py` 为本包自编，不是上游原脚本。

## 前提
确认目标 URL 与测试范围。优先本地或测试环境；不要默认在生产提交表单、购买、删除或改账号。需要登录时使用用户授权的方式，绝不把密码写进脚本。
查看项目启动命令，复用现有服务。没有服务时在获授权后启动，记录实际地址与端口；不要猜测应用一定监听 3000。

## 先侦察，后交互
打开真实 DOM，等待页面的具体就绪元素。长轮询或实时页面不强制等待 networkidle；超时要说明原因。
根据实际 role、文本、标签和稳定测试属性选取定位器。先截图和观察，再编写关键路径测试，不从截图随意臆造选择器。

## 自带只读冒烟检查
先读帮助：
```bash
python scripts/smoke.py --help
python scripts/smoke.py --url http://localhost:5173 --out ./qa-web
```
路径相对本技能目录；在项目中运行时使用脚本绝对路径。脚本默认只接受本机地址，并阻断页面发往外部的资源请求；已授权的远程目标或外部 CDN 资源需显式加 `--allow-remote`。授权页面自身的网络行为仍需用户确认。
它只记录指定页面的桌面/手机截图、标题、页面错误、失败请求和水平溢出，不点击、不提交表单、不代表 E2E 全测。页面若有持续加载，传入实际就绪 CSS：`--ready-selector '<selector>'`。

## 功能检查
按照需求检查导航、表单验证、核心流程、加载/空/错误状态。每项保存实际证据。浏览器不具备或无法启动时，只能报告静态审查，不能说网页测试通过。
测试结束关闭自己启动的浏览器；不要停止用户原本的服务。

## 交付
给出被测 URL、视口、动作与结果、截图位置、控制台错误、未覆盖部分。对源码修复后重跑受影响流程。
