# 从零开发项目：任务路由

只读取当前步骤需要的入口。简单任务省略无关步骤，不强制使用子代理，不批量加载全部内容。以下路径相对本场景目录。

- 需求、验收与最小项目：读取 `project-start/SKILL.md`。
- 增量实现或修复：读取 `test-driven-development/SKILL.md`。
- 报错定位：读取 `systematic-debugging/SKILL.md`。
- 项目含 Web 界面时：读取 `frontend-design/SKILL.md`。
- 有运行页面时：读取 `webapp-testing/SKILL.md`，先侦察再测试。
- 开发后审查：读取 `requesting-code-review/SKILL.md`。
- 交付前：读取 `verification-before-completion/SKILL.md`。

不要为了流程完整而给非 Web 项目强行增加前端；也不要未授权就部署或推送。

所有技能都服从用户已给定需求、真实工具能力和授权边界。先查看实际文件、日志或作品再判断；不得虚构测试、生成结果或上线状态。自动发现没有生效时，直接读取对应 SKILL.md，而不是臆造斜杠指令。
