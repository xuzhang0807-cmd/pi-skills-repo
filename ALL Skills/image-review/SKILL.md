# 图片成品审查

本次本地新编。`scripts/probe_image.py` 只检查文件信息，不自动评分审美。

## 必须先看实际图片
确认文件存在并能解码，按正确方向打开。只有文件名、提示词或尺寸时，不能评价人物、构图或生成质量。
可先做只读检查：
```bash
python scripts/probe_image.py --help
python scripts/probe_image.py input.png --output ./qa-image.json
```
脚本不修改原图，不输出 EXIF 中的 GPS、设备序列号等隐私字段。

## 检查内容
对照任务约束核查比例、用途、人物/产品身份、数量、姿势、道具、背景与文字。查看主体层级、留白、配色、光线、阴影、透视、裁切和边缘。
放大检查手部、五官、重复物体、模糊拼接、文字错字、标志变形及细小伪影。缩到实际使用尺寸检查可读性和主体辨识度。
审查修改图时对比真实原图，区分用户要求的变化与意外改动。不要从一张生成图推断未经证实的身份或真实事件。

## 记录问题
使用“位置 → 可观察问题 → 影响 → 精确修订指令”，最多先给最重要的几项。阻断交付的问题、一般瑕疵、纯审美建议分开。
不能仅凭直方图、文件大小或一个数字分数判断“高级感”。仅有来源信息不足时，不能断言素材许可已经合规。

## 结论
给出可交付/需修改/证据不足，并列已检查与未检查范围。需要修图时先保留原件，实际生成或编辑后再复查。
