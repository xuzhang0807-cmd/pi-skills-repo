# 渲染与导出

来源与适配差异见 [ORIGIN.md](ORIGIN.md)。

## 渲染前
确认实际工程入口、Composition ID、props、尺寸、帧率、时长、音轨和目标格式。先读取项目脚本与本地 CLI 帮助，不猜测合成 ID。
确认输出路径不会覆盖用户原片或上一版文件。检查素材是否可用、可用磁盘以及是否使用付费云服务；云任务需明确授权。

## 执行
上游基础入口：
```bash
npx remotion render
npx remotion still
```
在确认当前参数形式后传入明确的入口、合成 ID 和新输出路径。不要将上述交互式基础命令的开始执行视为渲染完成。
当前命令说明：
https://www.remotion.dev/docs/cli/render
https://www.remotion.dev/docs/cli/still

需要透明背景时，先查当前支持的容器、编码和像素格式；不能假设普通 MP4 一定保留透明通道。不擅自更改用户指定的规格。

## 实际验收
读取真实退出码与错误。成功后确认文件存在且非空，使用 FFprobe 或可用播放器检查宽高、时长、帧率和音轨，并查看关键画面。
用 `video-review` 做成片审查；失败时保留日志并指出失败阶段。没有完整播放就说明抽检覆盖范围。

## 交付
提供真实输出文件、实际规格、验证结果、已知限制以及必要的可重复渲染命令。不生成虚假路径，不把尚在队列中的任务报告为已完成。
