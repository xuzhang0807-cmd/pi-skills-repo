# skills：按场景取用的技能包

版本：2026.09.20。共 **17 个不重复技能**，分为 5 个场景。

**这是中文轻量适配版，不是上游原仓库镜像：12 个基于上游整理，5 个本次本地新编。** 保留上游技能名和可核对来源；修改点都在各技能的 `ORIGIN.md`。没有把新编技能冒充热门社区技能，也没有打包上游所有脚本与参考资料。

## 直接使用

1. 解压后，选择当前任务对应的场景文件夹。每个场景里是实际技能文件，不是下载链接或快捷方式。
2. 将该场景内含 `SKILL.md` 的技能子文件夹，按你当前客户端/CCS 支持的方式导入项目技能目录。也可以直接让 Agent 按明确文件路径读取使用。**不要将根目录当成一个 Skill 导入。**
3. 告诉 Agent：先读这个场景的 `AGENTS.md`，仅选择本次任务需要的技能执行。简单任务不必走完整套流程。

`AGENTS.md` 是路由说明，不保证每个客户端自动识别；未自动读取时，直接给 Agent 文件路径。此包没有改动你的电脑或 CCS 配置，也未在你的实际客户端中验证安装。

## 目录

| 文件夹 | 用途 | 场景内技能数 |
|---|---|---:|
| `01-日常项目部署检查维护` | 部署、Docker、故障定位、修复与验收 | 5 |
| `02-从零开发项目` | 需求落地、开发、测试、代码审查、交付 | 7 |
| `03-项目Web美化审查` | 视觉设计、界面规范、浏览器检查、代码审查 | 4 |
| `04-图片制作审美审查` | 图片构思、制作接口、成品检查 | 3 |
| `05-视频制作审美审查` | 分镜审美、生成接口、程序化制作、渲染、成品检查 | 5 |
| `ALL Skills` | 17 个技能的去重维护主库 | 17 |

场景之间复用同一个技能是正常的。**同一项目只安装一份同名技能；不要同时递归加载根目录、所有场景与 ALL Skills。** ALL Skills 是保存和维护用总库，不代表必须全部启用。目录里出现的 `deploy`、`ui`、`image` 等是记忆简称，不是本包已注册的斜杠命令。

## 来源和维护

- `SOURCES.md`：上游仓库、技能原地址、目录提交历史与入口 SHA。
- `UPDATE.md`：人工更新步骤，以及两个可选维护脚本。
- `manifest.json`：机器可读来源记录与本地文件校验值。
- 各技能的 `ORIGIN.md`：来源、依赖、改动内容。
- `CHECKS.md`：实际做过的检查与未验证范围。

## 需要另外具备的能力

审美规划可直接使用，但检查图片需要看图能力，完整视频审查需要实际播放与听取音频。图片/视频实际生成需要已授权的生成工具、API 和余额；`fal-ai-media` 不包含这些。

自带脚本按需使用：图片信息检查需要 Python 3.10+ 与 Pillow；视频探测需要 FFprobe，抽帧还需 FFmpeg；网页检查需要 Python Playwright 与 Chromium；Remotion 制作与渲染需要 Node.js、项目依赖和相应环境。具体见各场景说明。本包不自动安装软件、不写入密钥、不捆绑字体、不设置后台任务。
