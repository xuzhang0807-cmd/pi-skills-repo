# 视频成品审查

本次本地新编。先取得实际视频；不能只根据提示词、封面或文件名判断成片质量。

## 客观文件检查
先看帮助；脚本对源文件只读：
```bash
python scripts/probe_video.py --help
python scripts/probe_video.py input.mp4 --out ./qa-video
python scripts/probe_video.py input.mp4 --out ./qa-video-frames --frames 8
```
FFprobe 用于流与时长信息，抽帧另需 FFmpeg。输出目录应是新目录，防止覆盖以前的检查结果。
检查真实宽高、方向、时长、帧率、编码、音轨和可解码性。部分格式可能缺少字段，此时标为未知，不补猜值。

## 视觉与声音检查
尽可能完整观看并听取音频；按镜头和转场检查人物/物体一致性、手部、穿模、闪烁、运动方向、突然变形、重复帧、字幕、裁切和节奏。
声音检查包括是否存在、可听性、音画同步、突变、旁白内容和音乐遮盖；仅看到音轨元数据不代表听过声音。
只有抽帧条件时，明确采样数量和时间点。抽帧不能证明全片没有短暂闪烁、运动错误或音频问题；不得写“完整验收通过”。

## 报告
使用“时间点/范围 → 问题 → 证据 → 优先级 → 修改办法”。区分阻断交付、明显瑕疵和主观建议。
对照用户画幅、时长、分辨率与叙事要求逐项检查。输出能交付、需修改或证据不足，并明确未检部分。
修改后重新导出到新文件，再检查实际新版本，不复用旧版的验证结论。
