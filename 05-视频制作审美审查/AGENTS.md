# 视频制作、审美、审查：任务路由

只读取当前步骤需要的入口。简单任务省略无关步骤，不强制使用子代理，不批量加载全部内容。以下路径相对本场景目录。

- 故事、分镜、镜头、节奏、声音：读取 `video-plan/SKILL.md`。
- 生成式图生视频/文生视频：有获授权接口时读取 `fal-ai-media/SKILL.md`。
- 可编程图文动画、数据动画：读取 `remotion-create/SKILL.md`。
- 已有 Remotion 项目需要导出：读取 `remotion-render/SKILL.md`。
- 实际成片检查：读取 `video-review/SKILL.md`。

两条制作路线按任务选一种，不强制同时使用。Remotion 不是生成式真人视频模型。抽帧不是全片播放，音轨存在不代表已经试听。

所有技能都服从用户已给定需求、真实工具能力和授权边界。先查看实际文件、日志或作品再判断；不得虚构测试、生成结果或上线状态。自动发现没有生效时，直接读取对应 SKILL.md，而不是臆造斜杠指令。
