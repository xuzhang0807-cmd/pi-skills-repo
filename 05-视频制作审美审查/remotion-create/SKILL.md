# 创建程序化视频项目

来源与适配差异见 [ORIGIN.md](ORIGIN.md)。本版是独立起步流程，不包含整个 Remotion 技能库或运行软件。

## 项目检查
检查当前目录和隐藏文件。已有工程则复用其包管理器、锁文件、Remotion 版本与入口。非空目录不能为了脚手架清空；使用新的子目录，保留 .git、.env 和用户素材。
确认 Node.js、Git 和可用依赖。需要安装时告知将安装的内容；按当前官方说明核对脚手架命令，而非默默运行全局安装。
官方上游起步入口是 `npx create-video@latest`；空项目参数和实际版本以当前帮助为准。

## 编排
先用 `video-plan` 或用户已有分镜明确画幅、fps、总帧数和场景。按时间轴表达动画，使用当前 Remotion 支持的帧与插值 API，避免依赖随机时钟、未固定随机数或渲染期间不稳定的外部状态。
区分 Composition 与 Sequence；各镜头的开始、持续帧数与转场重叠应可计算。文字大小与安全边距面向最终视频尺寸，不照搬网页密集布局。
复用本地授权素材；未具备生成能力时不能用占位素材冒充最终镜头。声音、字体和图片加载需按当前官方方式确保渲染准备完成。

## 预览
按项目实际入口启动 Studio；当前常见入口为 `npx remotion studio --no-open`，先确认版本支持。
查看真实首帧、关键帧、转场和末帧，播放检查节奏、字幕与音画。服务没能启动或浏览器不可用时直接报告，不声称预览通过。

## 交付边界
用户只要工程时交付可运行工程、入口与未验证项。用户要求成片时再用 `remotion-render` 导出，不擅自调用付费云渲染。
当前 API 与文档以 https://www.remotion.dev/docs/ 为准；软件授权按上游条款核对。
