# 通过真实接口生成媒体

来源与适配差异见 [ORIGIN.md](ORIGIN.md)。这是调用流程，不是模型、额度或 MCP 安装包。

## 能力与授权检查
仅当用户明确选用 fal.ai，或已授权将其作为本次提供商时使用。检查实际已连接的 MCP/客户端和可用操作；不假设存在固定的 search/generate 等工具名。
没有已审核的客户端、密钥或额度时，说明缺失项，提供待执行方案；不要自行安装未知 MCP，不修改全局配置，不要求把密钥贴进聊天。

## 发现当前模型
使用提供商官方目录或当前客户端的发现能力，核对端点、输入 schema、支持的任务、参考图字段、尺寸、时长、音频、文件格式和费用。
仓库示例里的模型名和参数不能直接视为当前可用。种子也不保证跨模型或跨版本的身份一致性。

## 提交前
明确本次生成的数量、尺寸/时长、是否上传参考文件、预算与迭代上限。私有图片、客户资料、声音样本或视频不在未获授权时发送给第三方。
先做成本可控的单次试样；额外生成、高清放大或视频重试可能再次收费，不无上限循环。

## 执行与取回
按照实际 API schema 提交请求，记录任务 ID，不在日志输出认证头。异步任务只通过可用的查询接口检查状态；失败或超时保留真实状态，不编造结果，也不承诺在没有调度工具时后台继续观察。
仅从本次响应中的真实输出链接获取文件，保存到新路径，保留参考原件。验证文件能打开，确认尺寸、时长、声音等符合要求。

## 审查与交付
图片交给 `image-review`，视频交给 `video-review`；相关技能不在当前安装范围时按本次明确的验收项检查。
报告实际模型/端点、产物、生成状态、已知费用和未确认项。不要把文本提示词或任务提交成功说成媒体已完成。
